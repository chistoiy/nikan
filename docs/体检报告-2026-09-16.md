> 方法：`flutter analyze` / `flutter test` + 按条目定位代码现场（附 `文件:行号`）。

## 〇、本轮（2026-09-16 当天）已按本报告修复的项

| 条目 | 修复方式 |
|---|---|
| **A5** 缩放丢 EXIF 方向 | `resizeJpeg` 改用 `ImageDecoder.setTargetSize`（API 28+，无新依赖）：它**自动应用 EXIF 方向**，同时按目标尺寸直接解码，内存峰值大幅下降 |
| **A1** USB 下载全程持锁 | 取证后确认**锁不能按块释放**（整文件下载是单笔 GetObject 的数据相位，中途插事务会破坏它）。改为：下载期间保活**不发探针**，改用"最近是否还有下载进度"判活性（停滞 30s 判可疑）——既不再排队，又能真正发现断线 |
| **A4** 大文件取消无效 | 取消标志下沉到传输层：Wi-Fi 在分块边界检查（每块 4MB）、USB 在读块边界检查；新增 `CancelledException`（与故障区分，不重试、不计 failed）；USB 因数据相位残留会**作废连接并由下次事务自动重建**；UI 文案改成"已取消（已下载 N，剩余 M 张未传）" |
| **B2** 索引进度通知条件失效 | 改按"已补全详情的文件数"计数（原用 `files.length` 常量），并走 `_notifyThrottled()` |
| **B1** 每次通知都重排筛选 | 改**指纹比较**（files 身份/长度 + `indexedCount` + sortMode + 各筛选值 + 记录 revision）；手机页同一问题一并修掉 |
| **B6** `_cellKeys`/缩略图不回收 | 相册页在重新枚举时、手机页在记录变更时按当前主键集合裁剪 |
| **A3** 原图全分辨率解码 | 上半部分（查看器缓存）此前已改 LRU；本次给 `ZoomableImage` 加按显示尺寸的 `cacheWidth`，分"常态/放大"两档，**只缩不放**（小图不被放大解码），单张上限约 4K 宽 |

| **C2** USB 插入无处理 | 补 `MainActivity.onCreate/onNewIntent` → 转发给插件 → 连接页自动切 USB 模式并提示"检测到 XX 已通过 USB 接入"，可关闭提示 |
| **C4** 死代码 | 删 `CameraFile.dedupKey()`（且原实现 `$sizeOverride` 有 bug）；`ThumbCache.clearMemory()` 不是删而是**接上内存压力回调**（`didHaveMemoryPressure`） |
| **C5** `build_apk.bat` 损坏 | 两个脚本重写：修掉 0x07 控制字符、支持 `release` 参数、基号从 `.build_number` 自增、产物与核对命令都打印出来 |
| **C7** 文档与实现偏离 | `docs/技术方案.md` 顶部新增「实现与方案的差异」表（Riverpod→ChangeNotifier、drift→JSON、USB/遥控/删除都已做…） |
| **N1** 交接文档 §7/§11 过时 | §7 逐条标状态（实时取景、属性码标 ✅ 并**纠正原文错误的码映射**；息屏与 Auto ISO 标为"结论已定/搁置"）；§11 重排，已完成项移入"勿重复劳动"区 |

**仍未修（见下节，已排入待办）**：B3 排序语义、B4 待下载数量文案、B5 拖动命中测试、A6 的进一步优化、C8 测试与 lint 扩展。

## 四、建议的修复批次

### 批次 1：高价值低风险（建议立刻做，改动集中在 5 个文件）

- **A1** USB 下载不再全程持锁（保活不再饿死；这是"USB 下整卡同步 19 分钟"期间界面全程转圈的根因）
- **A4** 取消下沉到传输循环（用户在 4GB MOV 上点取消能真停）
- **A5** 缩放写出 EXIF 方向（**静默的数据质量缺陷**：竖拍照片变小横图，用户不会立刻发现）
- **B2** 索引进度通知条件改为按已索引计数（一行修正）
- **C5** 修好 `build_apk.bat/.sh` 并支持 release + 递增基号

### 批次 2：性能与内存（建议紧随其后）

- **B1** 缓存失效改为指纹比较（files 身份/长度 + sortMode + 筛选值）
- **A3** `zoom_image` 加按显示尺寸的 `cacheWidth`（中低端机 OOM 风险）
- **B5/B6** 命中测试换前缀表 + 二分；`_cellKeys/_thumbs` 随列表刷新裁剪

### 批次 3：零风险清理（可随时插入）

- **C4** 删死代码；**C7** 给 `技术方案.md` 加"实现与方案的差异"一节；**N1** 重写交接文档 §7/§11（把已解决项移到"已验证"）
- **C3** 换掉蓝牙图标 + 运行时申请通知权限；**C2** 要么实现插入即连、要么删掉声明
- **N3** 设置改用 `schemaVersion` 迁移；**N2** 清理 `dist/` 只留当前发布版
