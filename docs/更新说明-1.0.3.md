# NikonSync 1.0.3

这个版本聚焦一件事：**让"连相机"不再需要摸索**。连接过的相机会被记住、能自动重连；
Wi-Fi 连接里每一个"静默失败"或"把人说晕"的环节，这版都挑出来修掉了。

## 新功能

- **记住连接过的相机（支持多台）**：手机和电脑两条链路都以相机序列号归并，
  一台相机只有一条记录（热点名 / 密码 / 地址 / 备注名都在）。旧版本的单条记录自动迁移。
- **一键连接**：从「我的相机」里点一下即可——应用用存档的密码替你把 Wi-Fi 切到相机热点，
  连上后自动进入相机。热点名连输都不用输：由相机自身上报的数据推定
  （与相机屏幕显示的一致，标注"推定"、连接成功后自动转正）。
- **USB 自动连接**：插上数据线自动连接（应用主动探测 + 运行时广播双保险）；
  拔出再插也能再次自动连。
- **回到应用自动重连**：手机已在相机网络里时，切回应用就直接连上，不用再点。

## 修复（多数是"把人说晕"的环节）

- 权限授权框的结果此前**没人接收**，应用靠"等 3.6 秒"猜测用户点没点——现在改为
  精确等待授权结果，并区分"拒绝一次（可再弹）"与"系统不再弹（需去设置）"。
- 入网失败的提示此前会把原因说反（"已加入热点…但连接失败"，实际根本没连上）；
  现在单独归因，并按失败耗时区分"你在系统框上点了取消"与"密码问题"。
- 给旧记录补热点名时会**多出一条重复记录**——已改为就地更新。
- 应用不知道热点密码时，不再发起注定失败的"正在搜索设备…"搜索白等一分钟，
  直接给出两条真实出路（应用内填一次密码=之后全自动 / 系统面板每次手点）。
- 相机 Wi-Fi 刚开启时系统常搜不到热点：入网失败会**自动重试一次**，不用你再走流程。
- 下载过程中选择集锁定（点图=看大图，不会误取消选择）；查看器里也能直接勾选。
- 返回键逐层退：多选态先退多选、手机页返回回相机页，不再一按就退出应用。
- 遥控页的错误提示现在**点一下就能关**（此前只能等 8~12 秒超时）。

## 界面

- 相册页按天分组支持**折叠**；「手机」页补齐相册页的筛选 / 排序 / 分组能力（共用同一套组件）。
- 连接页重排：先看当前网络、再点连接；去掉重复的"添加相机"入口；
  USB 模式下不再出现"热点"字样，未插相机时按钮明确置灰。

## 说明

- Android 10+ 不允许应用读取系统 Wi-Fi 里保存的密码，也无法替你启用系统保存的网络
  （官方限制，`getConfiguredNetworks/enableNetwork/reconnect` 对普通应用为空操作）。
  因此相机热点密码需要在**应用内**填一次（相机屏幕上有），之后全自动；
  系统的连接确认框每次入网都会出现，属于平台强制。
- 部分系统（实测 HyperOS）禁用第三方应用的 Wi-Fi 扫描，热点名改为由相机自身上报
  数据推定，不影响使用。
