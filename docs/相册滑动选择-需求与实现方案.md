# 相册「滑动多选」需求与实现方案（可复用）

> 来源：本项目 `lib/pages/widgets/drag_selection.dart` + 相册页/手机页两处接入。
> 目的：把散落在代码与注释里的交互约定**固化成一份可验收的需求描述**，
> 供**另一个页面**或**另一个项目**照此实现，不必再从头设计，也不必再踩一遍坑。
>
> 适用范围：网格或列表形态的图片/文件浏览器，需要"长按起选 → 按住滑动批量勾/撤"的场景。

---

## 0. 一句话定义

**微信式滑动多选**：长按进入多选；按住不放横向/纵向滑动，按「起点 → 当前」的**连续区间**整体选中或取消；滑回来即反向操作；滑到视口上下边缘时自动慢滚以便继续选。

---

## 1. 术语

| 术语 | 说明 |
|---|---|
| **主键** | 条目的稳定标识（本项目相册用相机句柄 `handle`，手机页用记录键 `name:size`）。**不要用索引做选择集的键** |
| **锚点（anchor）** | 长按起点的索引。滑动期间不变 |
| **方向（dragAdd）** | 本次滑动是"加"还是"减"，由**锚点当时是否已选中**决定 |
| **选择集** | `Set<主键>`，唯一事实来源 |
| **选择模式** | 是否处于多选态（决定底栏、点击语义、格子勾选框显示） |

---

## 2. 交互需求（编号即验收项）

### 进入选择模式

- **R1** 长按任意单元格 → 进入选择模式 + 轻震动反馈 + 该格设为锚点 + 立刻把该格选中（若该格当前已选中，则本次方向为"取消"并立刻取消它）。
- **R2** 点单元格**右下角的勾选热区**（不遮挡缩略图的隐形区域）→ 进入选择模式并切换该项。用于不想长按的场景。
- **R3** 点分组头（如日期标题）→ 进入选择模式并整组切换（见 R9）。
- **R4** 选择集为空时，**自动退出选择模式**（用户把最后一项取消掉就回到了浏览态）。

### 滑动

- **R5** 滑动期间按**索引区间**整体操作：`[min(锚点, 当前) … max(锚点, 当前)]`，**按当前方向统一置位**（不是逐格 toggle）。
- **R6** 反向滑回 → 同一区间按同一方向回退（即"取消"模式下滑回会恢复）。
- **R7** 方向**实时跟随**：手指从下缘移回上缘时方向立刻反转，不需要抬手重按。
- **R8** 索引越界时钳到最后一个条目，不抛异常、不越界选中。

### 分组整选

- **R9** 点分组头 → **整组切换**（与该组全选同语义），且**必须同时进入选择模式**——否则点了分组头却看不到选择栏，选中状态也没法用。
- **R10** 分组头的文案要能看出当前是"全选当天"还是"取消选择"（本项目：`9月16日，128 张，点击全选当天`）。

### 全选 / 退出

- **R11** 全选与取消全选的**判定集合与操作集合必须是同一个**。否则只要选中集里含有被筛掉的条目，就会出现"显示未全选 → 点击后反而取消"的不一致（本项目历史 bug）。
- **R12** 退出选择：清空选择集、退出选择模式、停止自动滚动。

### 边缘自动滚动

- **R13** 指针进入视口**上下缘 90px** 内 → 每 16ms 滚动 7px（慢速，便于精确停在某行）。
- **R14** 滚动过程中用**保存的全局坐标**重新换算索引。用局部坐标会在滚动时反复命中第 0 行（本项目历史 bug）。
- **R15** 指针移出边缘区、抬手（up）、或手势被取消（cancel）→ 立刻停止滚动定时器。**up 与 cancel 都要处理**，否则定时器会一直跑。
- **R16** 列表已到底/到顶时钳住 `pixels`，不越界。

### 点击语义

- **R17** 非选择模式点格子 → 打开该项；**选择模式点格子** → 切换选中（不要再打开详情）。

## 3. 状态机

```
浏览态
 │ 长按单元格 / 点勾选热区 / 点分组头
 ▼
选择态 ──► 拖动中（有锚点 + 方向）
 │           │ 抬手 / cancel
 │           ▼
 │        选择态（保留选择集）
 │ 选择集被清空
 ▼
浏览态
```

必需状态字段：

```dart
final Set<T> selected = {};   // 唯一事实来源
bool selectMode = false;      // 是否处于多选态
bool dragSelecting = false;   // 是否正在拖动
bool dragAdd = true;          // 本次拖动方向
int? anchorIdx;               // 长按起点索引
```

**不变式**（实现时要注意维持）：
1. `selected.isEmpty` ⇒ `selectMode == false`（由 R4 保证）。
2. 退出拖动（`endDrag`）只清 `dragSelecting` 与 `anchorIdx`，**不清选择集**——拖完还要能继续点其它格子累加。
3. 任何改变选择集的操作都必须触发 `onChanged()` 一次（且只一次，避免重复重建）。

## 4. 屏幕坐标 → 条目索引（两种实现，按布局选一）

### 4.1 行高等宽网格 —— 用公式算（快，O(1)）

```dart
final cellW = (width - gap * (cols - 1)) / cols;
final cellH = cellW / cellAspect;                       // ⚠️ 与 GridView 的 childAspectRatio 必须同步
final scroll = scrollCtrl.hasClients ? scrollCtrl.offset : 0.0;
var row = ((scroll + local.dy) / (cellH + gap)).floor(); // ⚠️ 偏移项不能删
final col = (local.dx / (cellW + gap)).floor().clamp(0, cols - 1);
var idx = row * cols + col;
if (idx >= count) idx = count - 1;                       // R8
```

> **两个必踩的坑**：
> ① `(scroll + local.dy)` 里的滚动偏移项删掉后，滚动过的位置会算到错误的行。
> ② `cellH` 依赖 `childAspectRatio`；改 UI 的那一行尺寸时，这里必须同步改，
> 否则滑动选择会按错误的行距换算、选到别的行。

### 4.2 行高不固定（分组、夹着日期头）或列表 —— 用矩形命中测试

给每个单元格挂 `GlobalKey`，逐格判断：

```dart
for (var i = 0; i < items.length; i++) {
  final ctx = cellKeys[keyAt(i)]?.currentContext;
  if (ctx == null) continue;                     // 未构建的格子不可能命中
  final box = ctx.findRenderObject() as RenderBox?;
  if (box == null || !box.attached) continue;
  if ((box.localToGlobal(Offset.zero) & box.size).contains(global)) return i;
}
return null;
```

> **注意**：只有**已构建**（可见）的格子才有 `RenderBox`，所以命中的是"当前能看见的"那一格，
> 这正好符合直觉。代价是每次 `onPointerMove` 遍历整个列表（O(n)）。
> 本项目万级以内实测不是瓶颈；若真有十万级，应改成"section 高度前缀表 + 二分"，
> **不要**在行高不固定的布局里套用 4.1 的公式。

## 5. 与数据层的边界规则

- **D1** 列表刷新（重新枚举、换卡、删除记录）后必须 `prune(当前合法主键集合)`，
  否则"已选 N"会包含看不见的条目，"取消全选"也清不干净。
- **D2** 筛选/排序变化后同样要 `prune`——否则选中集里会残留被筛掉的条目，进而触发 R11 的不一致。
- **D3** `keyAt` / `itemCount` 必须**每次实时读取**（用闭包传入），不能在构造时快照；列表随时可能被刷新。
- **D4** 异步补全（本项目是"详情逐个加载"）会改变条目内容但不改变主键集合——**不要**因此清空选择集。
- **D5** 主键必须是稳定的业务标识；用索引会因为在列表头部插入一项而整体错位。

---

## 6. 性能规则

- **P1** 模型通知（下载进度、索引进度）**不等于**列表变化。缓存失效要按**指纹**判断
  （列表身份/长度 + 已补全数量 + 排序 + 各筛选值 + 记录版本号），
  否则每次通知都会重排整个列表并重建网格。
- **P2** `cellKeys`（GlobalKey）只增不减 → 列表刷新后按当前主键集合回收
  （`removeWhere((k, _) => !valid.contains(k))`）。
- **P3** 命中测试的 O(n) 只在**可见格**上做真正的渲染查询，其余是廉价的 map 查找；
  在万级以内先别优化，优化前先量。

## 7. 扩展点：联动与批量动作

- **E1** 任何"选中 A 就要带上 B"的联动（本项目是 RAW+JPEG 成对），
  **只挂在 `onChanged` 一处**。所有入口（点格子、点热区、长按滑动、全选、分组整选）
  最终都会走这个回调；分多处实现必然出现"点选联动、滑动不联动"的半生效。
- **E2** 联动要**双向**：选中带配对，取消也要带配对（否则配对会一直粘着，取消不掉）。
- **E3** 联动循环要加**重入守卫**（本项目 `_syncingPairs`），否则 A↔B 互相触发会死循环。
- **E4** 联动是**开关**（本项目 `linkRawJpegPairs`，默认开），因为确实有人只想收 JPEG。
- **E5** 批量动作（下载/删除/保护）的作用域要跟随筛选状态，并在文案里说清
  （本项目：`筛选范围内还有 N 张未下载` / `还有 N 张未下载`）。

## 8. 可参考的实现骨架

本项目把这一整套收敛成一个**与布局无关的状态机**，构造参数即全部差异点：

```dart
late final DragSelection<int> _sel = DragSelection<int>(
  keyAt:            (i) => _filtered[i].handle,   // 索引 → 主键
  itemCount:        () => _filtered.length,        // 实时条目数
  indexAt:          (g) => _groupByDay ? _hitIndex(g) : _indexAt(g), // 全局坐标 → 索引
  scrollController: _gridCtrl,
  viewportBox:      () => _gridKey.currentContext?.findRenderObject() as RenderBox?,
  onChanged:        () => setState(_syncPairs),    // 唯一重建入口 + 联动挂载点
);

// 手势宿主包在网格/列表外层（两种布局共用）
Widget _selectionHost(Widget child) => Listener(
  behavior: HitTestBehavior.translucent,
  onPointerMove:   (d) => _sel.updateDrag(d.position),
  onPointerUp:     (_) => _sel.endDrag(),
  onPointerCancel: (_) => _sel.endDrag(),
  child: child,
);

// 单元格
onTap:        () => _sel.selectMode ? _sel.toggle(handle) : _openViewer(index),
onLongPress:  () { HapticFeedback.mediumImpact(); _sel.beginDrag(index); },
onToggleSelect: () => _sel.enterSelectAndToggle(handle),  // 右下角勾选热区
```

对外 API：`toggle / enterSelectAndToggle / exitSelect / prune / allSelected /
toggleAll / toggleGroup / beginDrag / updateDrag / endDrag / dispose`。

## 9. 验收用例清单（照此逐条测）

- [ ] 长按第 3 格 → 进入多选、有震动、第 3 格被选中
- [ ] 长按一个**已选中**的格子 → 本次方向为取消，松手前滑过的都被取消
- [ ] 从第 3 格滑到第 20 格 → 3~20 全部选中（连续区间，不是逐格翻转）
- [ ] 从第 20 格滑回第 3 格 → 3~20 全部恢复为未选
- [ ] 滑到视口下缘 → 自动慢速滚动，且**滚动中命中的行是正确的**（不是一直第 0 行）
- [ ] 滚动到底后继续按住 → 停在最底部，不越界、不报错
- [ ] 手指移出边缘区 → 立刻停止滚动
- [ ] 中途抬手 → 选择集保留，可以继续点其它格子累加
- [ ] 点右下角勾选热区 → 直接进入多选并切换该格（不需要长按）
- [ ] 按日期分组 → 点日期头 → 整组选中，且选择栏出现
- [ ] 再点一次日期头 → 整组取消；若此时选择集为空 → 自动退回浏览态
- [ ] 全选 → 取消全选 → 反复 3 次，状态与文案始终一致（R11）
- [ ] 在筛选状态下全选 → 只作用于筛选结果，"已选 N"与实际一致
- [ ] 切换筛选/排序 → 被筛掉的选中项被剔除，"已选 N"不虚高
- [ ] 选择模式下点格子 → 只切换选中，**不会**打开大图
- [ ] 刷新/换卡后 → 失效的主键被清理
- [ ] 开启成对联动时：点选 / 长按滑动 / 全选 / 分组整选 **四种入口都**会带上配对文件
- [ ] 取消其中一张 → 配对的另一张也一起取消

## 10. 本项目踩过的坑（实现时照着避）

| 现象 | 根因 |
|---|---|
| 边缘滚动时反复选中第 0 行 | 用**局部**坐标重算索引；应保存并使用**全局**坐标 |
| 滚动过之后选到别的行 | 行列公式里漏了 `scroll +` 偏移项 |
| 改了格子宽高比后选错行 | `cellH` 与 `childAspectRatio` 不同步 |
| 点了分组头没反应/看不到选择栏 | 整组切换没有同时进入选择模式 |
| "显示未全选，点击反而取消" | 全选的判定集合与操作集合不是同一个 |
| 取消/回连后"已选 N"虚高 | 列表刷新后没 `prune` |
| 点选会联动、滑动不联动 | 联动写在了多个入口，而不是 `onChanged` 一处 |
| 定时器停不下来 | 只处理了 `onPointerUp`，漏了 `onPointerCancel` |
| 配对文件取消不掉 | 联动只做了"选中带上"，没做"取消带下" |

## 11. 复用清单（换一个页面/项目时的改动点）

1. 决定主键类型 `T`（句柄、记录键、文件 id…）。
2. 决定坐标换算：行高固定 → 4.1 公式；不固定 → 4.2 命中测试（记得给单元格挂 `GlobalKey`，并在列表刷新时回收）。
3. 把状态机挂到页面：构造参数 + `Listener` 手势宿主 + 单元格的三个回调。
4. 接上 `prune`（列表刷新时）与 `onChanged` 里的重建/联动。
5. 提供底栏：已选数量、全选、取消、批量动作（作用域跟随筛选，并在文案中说明）。
6. 按第 9 节逐条验收。
