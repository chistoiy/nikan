# 尼康速传 v1.0.0

尼康 Z 系列相机 Wi-Fi 照片传输与遥控应用（Android）。

无需尼康官方 App、无需配对工具——手机直连相机 Wi-Fi，浏览、批量下载相机存储卡中的照片，支持实时取景遥控拍摄。

## ✨ 功能

**照片传输**
- Wi-Fi 免配对直连，连接即用
- 快速枚举（1500 文件 <1s），缩略图按需加载
- 滑动范围多选（微信式）、批量下载
- 三档画质：原图 / 8M / 2M
- 保存到系统相册或自定义目录，自动去重
- 按日期分组、JPEG/RAW/视频筛选、多种排序
- 下载后删除相机原片（可选）

**遥控拍摄**
- 盲拍模式（远程快门）
- 实时取景模式（手机实时显示相机画面）
- 取景中拍摄、远程对焦
- 拍摄参数显示（光圈/快门/ISO/电量）
- 对焦优先机型（未对焦禁止拍摄）自动处理

**稳定性**
- 后台连接保活（通知栏常驻）
- 断线即时检测与重连
- 全局错误捕获

## 📦 下载安装

| 文件 | 适用设备 |
|---|---|
| `NikonSync-v1.0.0-arm64.apk` | 2019 年后的绝大多数手机（推荐，约 16MB）|
| `NikonSync-v1.0.0-arm32.apk` | 老款 32 位设备（约 14MB）|

1. 下载 APK 到手机，点击安装（需允许"安装未知来源应用"）
2. 若之前安装过旧测试版，请先卸载旧版再安装

**使用前提**：Android 10+；尼康相机支持智能设备 Wi-Fi 连接（已验证：Z50 II 固件 1.02）

## 📷 使用方法

1. 相机：MENU → 扳手 → 连接至智能设备 → Wi-Fi 连接 → 建立连接（屏幕显示 SSID/密码）
2. 手机：连接相机屏幕显示的 Wi-Fi 热点（名称形如 `Z50_2_XXXX`）
3. 打开尼康速传 → 连接相机 → 浏览/下载/遥控拍摄

## ⚠️ 已知限制

- 实时取景帧率约 5~10fps（受相机热点带宽限制，建议相机端启用 5GHz Wi-Fi）
- 相机开启"未对焦时禁止拍摄"时，需先完成对焦才能拍摄（App 会明确提示）
- 部分尼康厂商协议为社区逆向成果，相机固件更新可能影响兼容性
- RAW (NEF) 原样传输，App 内预览使用内嵌缩略图
