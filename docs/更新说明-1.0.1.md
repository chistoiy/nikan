## 二、新功能

### 1. USB 数据线连接（速度提升 11 倍）

- 与 Wi-Fi 完全共用同一套上层逻辑（相册、下载、遥控都是同一个界面），不需要学第二套操作；
- 实测 **27.1 MB/s**，Wi-Fi 智能设备模式的上限约 1.5~2.4 MB/s；
- 连接页现在**默认只显示 Wi-Fi**，需要 USB 时点上方「USB」切换，两种方式的步骤各自成卡、
  默认折叠——不再一打开就被大段指导挡住连接按钮。

USB 使用前置条件（在 App 的连接页里也有说明）：相机 **MENU → 网络菜单 → 连接至智能设备 →
选「关闭」**，再把 **MENU → 网络菜单 → USB → 选「MTP/PTP」**，然后连线并在手机上点「允许访问设备」。

### 2. 相册：批量挑选快了很多

- **按住滑动批量选择**：手指按住后横向/纵向滑过即连续勾选，滑回来会取消，指到边缘会自动滚动；
- **按拍摄日期分组**：筛选条点「按日期」即可，点日期头**整选当天全部**；
- **只看未下载**：一键筛出还没收到的照片，配合「一键下载」补齐；
- **待下载任务条**：显示还有多少张没下、支持一键补下。

### 3. 大图查看器：三档画质 + 真实进度

- **低 / 中 / 原图**三档：默认「中」是相机端出的高清图（1620×1080，约 880KB），
  清晰度与等待时间兼顾；
- 点「显示原图」时有**真实进度**：百分比、已接收/总量、实时速率、已用秒数；
  **8 秒收不到新数据会转成警示态**并说明可能原因（相机在忙 / 链路可能已断）；
- 可选**把原图一并保存到手机**（默认关，避免"只想看一眼却多出一堆文件"）。

### 4. 遥控拍摄

- **参数可直接在手机上改**：光圈 / 快门 / ISO / 曝光补偿，按当前档位判断能不能改，
  改完立即回读确认；
- 参数会**跟着相机动**：相机自动改变的光圈/ISO 会同步显示到手机上；
- **点取景画面指定对焦点**：对焦框在手机上常驻显示，并按状态着色
  （白=正在对焦 / 黄=已指定 / 橙=相机未接受该点 / 红=失败）；
- **盲拍模式**：不进入实时取景也能触发快门（省电、长曝光、相机不在取景界面时的兜底）。

### 5. RAW+JPEG 成对处理

相机开「RAW + JPEG 同时记录」时，同一张照片在相机上是两个文件。现在：

- 相册自动识别成对文件，右上角显示 **`R+J`** 角标；
- 左下角下载状态**分列显示**：`J✓ R○` 表示 JPEG 已下载、RAW 还没下；
- **勾选其中一张会自动带上另一半**（可在设置里关闭）；
- 筛选条新增「**成对 N**」，只看成对照片，便于成对下载或成对清理。

### 6. 链路状态看得见

- AppBar 上的**信号格**来自 Wi-Fi 真实强度；
- 点开是**诊断面板**：Wi-Fi 信号（格数 / dBm / 速率）、距上次相机消息时间、保活探针往返耗时——
  用来区分"相机在忙"和"链路已断"。

### 7. 新图标

新的启动图标：外圈带箭头的同步环（无线传输）+ 内圈镜头 + 中心对焦点，
深色渐变底配应用主题黄；已包含自适应图标与 Android 13 主题图标。

## 三、重要修复

| 问题 | 说明 |
|---|---|
| **Wi-Fi 下改参数永远失败** | 根因是 PTP/IP「数据外发」报文把事务号字段写成了偏移量，相机一律回 `TransactionCancelled`。这是本版最有价值的一个修复。 |
| 相机息屏后遥控失效 | 现在会明确判定并提示"相机可能已进入待机"，给出唤醒与长期解决方案；不再让用户面对一个无限转圈的取景窗。 |
| 空闲后假掉线 | 单次读超时不再作废整条连接（区分"超时落在包边界"与"半个包残留在流里"）。 |
| 保活探针发错操作码 | 旧代码用的 0x90C1 实际是「AF 驱动」，等于每 5 秒驱动一次对焦；已改为只读探测。 |
| 对焦优先机型拍不了 | 改为先合焦再按快门，重试不再打断自动对焦，失败时给出相机菜单路径。 |
| 点击对焦位置对不上 | 对焦倍数改为**从取景帧头部自动解出**（相机图像尺寸 5568×3712 ÷ 取景帧 640×424），不再靠肉眼标定。 |
| USB 路径三个硬 bug | 读缓冲处理、目录枚举递归、大文件传输；修完实测 27.1 MB/s。 |
| 相册状态条堆叠 | 三条状态条合并为一条（按优先级显示），不再挤掉网格。 |
| 重复连接打断相机 | 重复点连接不再重新握手；两个入口的连接状态保持一致。 |
| 下载完整性 | 传输量与声明不一致时显式失败并说明原因，不静默留下半个文件。 |

## 四、已知限制（发布时建议一并说明）

1. **相机息屏后遥控不可用**：Z50 II 在 Wi-Fi 智能设备模式下不提供任何息屏/待机属性，
   App 无法延长；请在相机 **MENU → 自定义设定菜单 → c3「电源关闭延迟」** 调长时间。
   相机待机后连快门也会被拒——这是相机行为，不是 App 故障。
2. **Wi-Fi 速度有上限**：智能设备模式约 1.5~2.4 MB/s；大批量传输请用 USB 数据线。
3. **RAW 无法在手机上看原图**：App 内 RAW 只有缩略图（RAW 解码不在本项目范围内）。
4. **机型范围**：目前只在 Nikon Z50 II（固件 1.02）上完整验证过。
5. 本 App 为非官方工具，与尼康公司无关。
