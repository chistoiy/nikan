# 尼康速传（NikonSync）

尼康 Z 系列相机 Wi-Fi 照片传输与遥控 Android 应用。Flutter UI + Kotlin 原生 PTP/IP 协议引擎，无需尼康官方 App、无需配对工具。

> 本项目为非官方开源作品，与尼康公司无关。使用后果自负，请勿用于重要数据的唯一存储场景。

## 功能

**照片传输**
- Wi-Fi 直连相机（免配对握手，连接即用）
- 目录式快速枚举（1500 文件约 0.3s）+ 缩略图按需加载（内存/磁盘两级缓存）
- 滑动范围多选（微信式）+ 批量下载，支持原图 / 8M / 2M 三档画质
- 保存到系统相册或自定义目录（SAF），按"文件名+画质"去重，支持下载后删除相机原片
- 按日期分组、类型筛选（JPEG/RAW/视频）、多种排序

**遥控拍摄**
- 盲拍模式：远程快门（照片写入存储卡）
- 实时取景模式：手机实时显示相机画面 + 远程拍摄
- 对焦驱动、拍摄参数显示（光圈/快门/ISO/电量）
- 对焦优先机型（未对焦禁止拍摄）自动处理与明确提示

**稳定性**
- 后台连接保活（前台服务 + WifiLock）
- 断线即时检测、自动重连
- 全局错误捕获（堆栈进日志面板，便于反馈）

## 架构

```
Flutter UI ──MethodChannel/EventChannel──> Kotlin PTP/IP 协议引擎 ──TCP 15740──> 相机
```

- 握手采用尼康官方 App（WMU）同款固定 GUID，相机视为已配对主机直接放行完整操作集
- 协议事务串行 + 优先级调度；缩略图/大图两级缓存；下载分块+自动降级

## 构建

```bash
flutter pub get
FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn flutter build apk --debug
# 产物：build/app/outputs/flutter-apk/app-debug.apk（也可双击 build_apk.bat）
```

- 仅支持 Android（minSdk 29）
- 必须使用 flutter-io.cn 镜像变量（其他镜像缺 Flutter 引擎 Maven 构件）

## 使用

1. 相机：MENU → 扳手 → 连接至智能设备 → Wi-Fi 连接 → 建立连接（显示 SSID/密码）
2. 手机连接该热点，打开 App → 连接相机
3. 浏览/选择/下载；遥控拍摄；设置页（齿轮）内有协议调试面板

已验证机型：Nikon Z50 II（固件 1.02）。理论兼容同代智能设备 Wi-Fi 模式的 Z 系列机身，未逐一测试。

## 已知限制

- 实时取景 16~31fps、画面 640×424（这是相机在智能设备 Wi-Fi 模式下的取景流规格上限，
  不是本应用的限制）。取景画面发闷也源于此：640×424 放大到手机屏，且压缩较重
- 相机横放时取景画面需要手动旋转（取景画面左下角按钮）——实测该机型取景帧
  不带 EXIF 方向标记，无法自动识别
- 取景中的远程对焦依赖相机对焦优先设置，部分场景需半按相机快门辅助
- 尼康厂商协议部分操作码为社区逆向成果，固件更新可能导致行为变化
